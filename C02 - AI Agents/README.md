## Cours sur les agents LLM.

Les outils d'IA devenant de plus en plus puissants, il est maintenant indispensable d'apprendre à s'en servir correctement.

On verra toutes les fonctionnalités importantes des agents LLM de code et comment s'en servir, ainsi que les bonnes pratiques pour générer du code. Puis on génèrera un mini projet en one-shot!

Voilà quelques sujets qu'on va aborder pendant cette séance, en bref :

Les fonctionnalitées importantes d'un agent:
Outils intégrés, Serveurs MCP, Gestion de la fenêtre de contexte, RAG, Taches de fond
Comment comparer les modèles et en choisir un?
Comment utiliser un agent?
Prompt engineering, Planification de taches, enrichissement du contexte, System prompts, Fichier de règles

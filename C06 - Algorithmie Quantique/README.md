## Script Python

`grover.py` est un script Python qui implémente une démonstration simple de l'algorithme de Grover avec un simulateur local.

Tu peux changer le nombre d'itérations de l'algorithme en modifiant la variable `num_iterations` dans le script. Laisse la à 0 pour calculer le nombre optimal d'itérations.

Pour l'exécuter, assurez-vous d'avoir installé les dépendances nécessaires (dans `requirements.txt`).
